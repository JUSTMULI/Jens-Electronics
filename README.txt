JENS ELECTRONICS - Products Page

Upload to the ROOT of your existing JENS-ELECTRONICS GitHub repository:
- products.html
- css/products.css  (inside css folder)
- js/products.js    (inside js folder)

DO NOT delete your existing index.html, css/style.css, or js/script.js.

IMPORTANT: Open js/products.js and replace the empty WHATSAPP_NUMBER with your verified business WhatsApp number, for example 2547XXXXXXXX. Without this, ordering buttons show a setup message rather than opening a wrong number.

The catalog currently has category-level sample listings with NO prices or stock promises. Edit the products array to add real items and confirmed prices later.

Your existing homepage Products link will point to products.html and the category links will work with the ?category=... query parameter.
